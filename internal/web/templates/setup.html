Secure access

Installing wha as an app and enabling offline support both require a secure (HTTPS) connection. If this deployment runs behind a reverse proxy with an internal certificate authority (e.g. Caddy's tls internal), trust its root certificate below on each device you use.

A website cannot silently install a root certificate into your device's trust store — every platform requires a few manual taps to install and confirm trust. The steps below are the shortest path per device.

Per-device install steps

iOS / iPadOS
  1. Download the iOS/macOS configuration profile above in Safari.
  2. Open Settings → General → VPN & Device Management and tap the downloaded profile.
  3. Tap Install, then Settings → General → About → Certificate Trust Settings and enable full trust for the "wha secure access root CA" certificate.
  4. Reload the wha dashboard in Safari, then use the Share sheet → Add to Home Screen.
Android
  1. Download the root certificate above in Chrome.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate and select the downloaded file.
  3. Reload the wha dashboard in Chrome; when the install banner or menu shows Install app, tap it.
macOS
  1. Download the root certificate above, or run the helper script: scripts/trust-ca.sh.
  2. If installing manually, open it in Keychain Access, add it to the System keychain, then double-click it and set Trust → Always Trust.
Windows
  1. Download the root certificate above, or run the helper script as Administrator: scripts/trust-ca.ps1.
  2. If installing manually, double-click the file, choose Local Machine → Trusted Root Certification Authorities, then finish the wizard.
Linux (Debian/Ubuntu)
  1. Run the helper script: scripts/trust-ca.sh (copies the cert to /usr/local/share/ca-certificates and runs update-ca-certificates).

Install as an app

Once the connection is trusted (or you're on localhost), reload this dashboard and use your browser's install prompt — or the Share sheet's "Add to Home Screen" on iOS — to add wha to your home screen. It launches full-screen and keeps a basic offline shell if the connection drops.
